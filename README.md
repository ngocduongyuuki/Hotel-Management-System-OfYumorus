## English

### 📌 Introduction

Hotel Management System is a web-based application designed to support basic hotel management operations. The system provides an interactive interface for managing room reservations, checking room availability, calculating booking costs, and handling customer information.

This project was developed as a web programming project to demonstrate the implementation of user interfaces and interactive website functionalities.

### ✨ Key Features

- **Room Booking:** Create and manage hotel room reservations.
- **Flexible Booking:** Support hourly, daily, and overnight booking options.
- **Price Calculation:** Calculate booking costs and deposits based on reservation details.
- **Room Availability:** Check room availability and prevent overlapping reservations.
- **Reservation Management:** Review, approve, and cancel bookings.
- **Room Management:** Manage hotel room information and status.
- **Customer Management:** Store and manage customer information.

### 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

### 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Hotel-Management-System.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation is required if the application uses only resources included in the HTML file or accessible through its external dependencies.

## Tiếng Việt

### 📌 Giới thiệu

Hotel Management System là một ứng dụng web được xây dựng nhằm hỗ trợ các nghiệp vụ quản lý khách sạn cơ bản. Hệ thống cung cấp giao diện tương tác giúp quản lý đặt phòng, kiểm tra tình trạng phòng, tính toán chi phí đặt phòng và xử lý thông tin khách hàng.

Dự án được thực hiện trong khuôn khổ môn học Lập trình Web, nhằm thể hiện khả năng xây dựng giao diện và triển khai các chức năng tương tác trên website.

### ✨ Các chức năng chính

- **Đặt phòng:** Tạo và quản lý các yêu cầu đặt phòng khách sạn.
- **Đặt phòng linh hoạt:** Hỗ trợ các hình thức thuê theo giờ, theo ngày và qua đêm.
- **Tính toán chi phí:** Tự động tính tiền phòng và tiền đặt cọc dựa trên thông tin đặt phòng.
- **Kiểm tra phòng trống:** Kiểm tra tình trạng phòng và hạn chế trùng lịch đặt phòng.
- **Quản lý đặt phòng:** Xem xét, xác nhận và hủy các yêu cầu đặt phòng.
- **Quản lý phòng:** Quản lý thông tin và trạng thái của từng phòng.
- **Quản lý khách hàng:** Lưu trữ và quản lý thông tin khách hàng.
